# Parth Mobile Distribution

Mini ERP + CRM Operations Portal

## Current Status

Milestone 1 — Project Foundation

## Tech Stack

Frontend:
React + TypeScript + Vite

Backend:
Node.js + TypeScript + Express

Database:
PostgreSQL (to be implemented)

## Project Structure

- `frontend/`: React + Vite application shell
- `backend/`: Express + Node API skeleton

## Local Development

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
